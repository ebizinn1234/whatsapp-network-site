# 🚀 Deploy no Railway (GRATUITO)

## Passo a passo para colocar online:

### 1. Criar conta no Railway
- Acesse: https://railway.app
- Clique em "Login" → "GitHub"
- Autorize o Railway

### 2. Conectar repositório
- Clique em "New Project"
- Selecione "Deploy from GitHub repo"
- Escolha seu repositório ou faça upload dos arquivos

### 3. Configurar variáveis (se necessário)
- PORT: 3000 (já configurado)
- NODE_ENV: production

### 4. Deploy automático
- Railway detecta automaticamente que é Node.js
- Instala dependências automaticamente
- Inicia o servidor

### 5. Acessar seu site
- Railway gera uma URL como: `https://seu-projeto.railway.app`
- Compartilhe com seus usuários!
